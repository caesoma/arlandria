# Repo guidance for agents

This package adds a `callimachus` and a `hypatia` skill to Pi. The workflow lives in `skills/callimachus/SKILL.md` and the `/litreview` prompt. The review state lives in a per-review folder's `ledger.json` (the ledger; the folder also holds `exports/`, `searches/`, `pdfs/`) — its schema is in `skills/callimachus/references/ledger_schema.md`. Records are never deleted.
